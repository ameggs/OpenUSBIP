================================================================================
                         TECHNOLOGY STACK
================================================================================

Language:     Python 3.10+
GUI:          PySide6 (Qt6) - cross-platform, professional
Discovery:    zeroconf (mDNS/Avahi)
Config:       PyYAML
Backend:      Linux kernel USB/IP, usbipd-win, usbip-win2

Platforms:
  • Linux (client & server) - kernel USB/IP
  • Windows (client) - usbip-win2 drivers
  • Windows (server) - usbipd-win
  • Raspberry Pi (server) - kernel USB/IP + mDNS
  • macOS (future) - via jiegec/usbip Rust library

================================================================================
                         ARCHITECTURE
================================================================================

Client Mode:
  1. Auto-discover Raspberry Pi servers (mDNS)
  2. List available USB devices on each server
  3. Attach devices with one click
  4. Detach when done
  5. Remember servers and auto-connect preferences

Server Mode (Raspberry Pi):
  1. Advertise via mDNS
  2. Share USB devices
  3. Show connection status
  4. Manage device bindings

Network:
  • Port 3240 (USB/IP standard)
  • mDNS for discovery
  • Works on LAN (Ethernet/WiFi)

================================================================================
                         USAGE EXAMPLES
================================================================================

Install Dependencies:
  cd ~/OpenUSBIP
  ./setup.sh

Run Client (when GUI is complete):
  python3 openusbip_client.py

Test Core Functionality Now:
  python3 -c "
  import sys
  sys.path.insert(0, 'src')
  from core.usbip_wrapper import USBIPWrapper
  w = USBIPWrapper()
  print(f'USB/IP Available: {w.is_available()}')
  print('Local Devices:')
  for d in w.list_local_devices():
      print(f'  {d}')
  "

Raspberry Pi Server Setup:
  # On Raspberry Pi
  sudo apt install linux-tools-generic avahi-daemon
  sudo modprobe usbip_host
  sudo usbipd -D
  
  # Run OpenUSBIP server (when complete)
  python3 openusbip_server.py

                         PROJECT GOALS
================================================================================

PRIMARY GOAL:
  Create a free, open-source alternative to VirtualHere for personal use

KEY FEATURES:
  ✅ Cross-platform (Windows, Linux, Raspberry Pi)
  ✅ Auto-discovery of Raspberry Pi servers
  ✅ Easy-to-use GUI
  ✅ No licensing fees
  ✅ Optimized for homelab/personal network

NOT GOALS:
  ❌ Commercial distribution
  ❌ Enterprise features
  ❌ Cloud/internet access (LAN only for now)
  ❌ Mobile apps (Android/iOS)
